# TechBlog Application

A responsive technology blogging website built using HTML, CSS, and JavaScript to provide users with a clean and user-friendly platform for exploring blog content.

## 🚀 Live Demo

[View Live Website](https://bolg-project.vercel.app/)

## 📌 About the Project

TechBlog is a frontend web development project designed to present technology-related articles through an organized and responsive interface. It includes separate pages for browsing blogs, viewing individual posts, learning about the platform, and contacting the website.

## ✨ Features

- **Responsive Design:** Adapts the interface to desktop, tablet, and mobile screens.
- **Blog Listing:** Displays blog content in an organized layout.
- **Individual Blog Posts:** Provides a dedicated page for reading blog articles.
- **About Page:** Presents information about the platform.
- **Contact Page:** Provides a dedicated interface for contact-related information.
- **Clean UI:** Uses structured layouts, consistent styling, and intuitive navigation.

## 🛠️ Tech Stack

- **HTML5** – Structures the website pages and content.
- **CSS3** – Handles styling, layouts, and responsive design.
- **JavaScript** – Adds client-side functionality and interactivity.
- **Vercel** – Hosts and deploys the website.
- **Git & GitHub** – Supports version control and source code management.

## 📂 Project Structure

```text
bolg-project/
├── css/              # Stylesheets
├── data/             # Blog-related data
├── js/               # JavaScript files
├── index.html        # Home page
├── blog.html         # Blog listing page
├── blog-post.html    # Individual blog post page
├── about.html        # About page
└── contact.html      # Contact page
```

## ⚙️ Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/rishikumarsingh123/bolg-project.git
   ```

2. Navigate to the project directory:

   ```bash
   cd bolg-project
   ```

3. Open `index.html` in your browser, or use the Live Server extension in VS Code for local development.
